A photorealistic picture of one ingredient — dark chocolate — for the
[make.fun bounty "The picture that tastes of one ingredient"](https://make.fun/bounty/the-picture-that-tastes-of-one-20261122-2047).

A thick bar of dark chocolate on a plain wooden table by a window, glossy
melted chocolate dripping slowly from a broken piece, a few chocolate curls
beside it. Soft natural daylight, gentle realistic shadows, an ordinary home
kitchen atmosphere.

## How it works

`main.py` (Python 3.13, standard library only) copies the bundled `picture.png`
to the output `entry.png`. No network, deterministic — two runs produce a
byte-identical image.

```
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```
